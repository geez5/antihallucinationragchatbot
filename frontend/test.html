Meet Veritas —
the anti-hallucination chatbot

A RAG-powered chat widget that only answers from your website content. 10 layers of hallucination prevention. Zero made-up answers.

Backend target:  http://localhost:8000  — Make sure uvicorn main:app --reload is running in the backend/ folder before testing.

How hallucinations are prevented

10 layers working together

L1 Intent classifier blocks off-topic questions
L2 ChromaDB vector retrieval — top 10 candidates
L3 Cosine similarity threshold ≥ 0.70
L4 Jina AI reranker picks best 3 chunks
L5 temperature=0 — no LLM randomness
L6 Strict system prompt — context only
L7 Token cap — max 512 output tokens
L8 Guardrail self-check — second LLM verifies
L9 Source citation on every response
L10 Freshness — nightly recrawl of website
Local testing

What to test in the widget

1
Starter questions
Click any of the 3 chips on open. Should send a real question.
2
On-topic answer
Ask What services do you offer? — expect a real answer + source link.
3
Off-topic block
Ask Who won the World Cup? — should be blocked by L1.
4
Feedback buttons
Click 👍 or 👎 — buttons should swap to a thank-you message.
5
Follow-up question
Ask a follow-up like Tell me more — history is sent.
6
Rate limit
Send 20+ rapid messages — widget shows a polite wait message.
